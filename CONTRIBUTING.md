# Contributing

Thanks for helping improve Meme Radar.

## Before opening a change

```bash
npm run typecheck
npm test
npm run demo
```

Keep changes focused and preserve the read-only boundary. New scoring behavior should include deterministic tests and a terminal explanation. Do not commit `.env`, RPC credentials, generated `dist/`, or `node_modules/`.

## Pull requests

Please describe:

- what evidence changed;
- how missing data behaves;
- how the change was tested;
- whether the README or limitations need an update.
